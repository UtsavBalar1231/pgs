# pgs presentation kit

[← Project overview](../README.md)

The presentation centers on one concrete benefit: give your coding agent the tools to
commit a fix without taking an unrelated debug statement along with it.
The visual language uses GitHub dark colors, bold type, a detailed agent
workspace, and camera moves that settle for reading.

| Asset | Use |
|-------|-----|
| [Launch film](assets/pgs-launch.mp4) | 35 seconds, 1920×1080. Project launches, talks, release announcements. |
| [Square film](assets/pgs-social.mp4) | 12 seconds, 1080×1080. Social feeds and compact embeds. |
| [Social card](assets/social-card.png) | 1280×640. GitHub social preview, link cards, README banner. |
| [Poster](assets/launch-poster.png) | 1920×1080. Thumbnail showing the agent previewing the exact selected line. |
| [Selection mark](assets/mark.svg) | Scalable project avatar and icon. |
| [Staged-patch icon kit](assets/pgs-icon/README.md) | Orange illustrated icon, SVG, transparent PNG, editable Lottie, GIF and MP4 previews. |
| [Editable source](../media/launch/README.md) | Remotion scenes, local fonts, original synthesized score. |
| [Creative research](../media/launch/CREATIVE.md) | Sources, rationale, storyboard, and technical truth. |

Both films have original sound and music, no voiceover, and readable on-screen
copy. The screen layouts illustrate verified behavior; they are not a recording
of a graphical pgs interface.

## Copy to reuse

Short description:

> Precise Git staging for coding agents.

One paragraph:

> pgs helps a coding agent turn a mixed working tree into focused commits.
> Select files, hunks, or exact lines; preview what will be staged; and commit
> through a CLI or a local MCP server. An included skill teaches the workflow.

Release or social post:

> The fix is ready. The debug line can wait.
>
> pgs lets your coding agent choose the exact lines that belong in a commit.
> Local MCP server and an included workflow skill. Linux, macOS, Windows. MIT licensed.
>
> https://github.com/UtsavBalar1231/pgs

## Placement

Use `social-card.png` in GitHub repository settings under Social preview.
Attach the MP4 directly when posting a launch; link to the repository for
installation. The root README uses the same card and links to the film.
The Codex plugin metadata uses the matching GitHub blue brand color.

Public repository settings and social accounts have not been changed.

The SVG artwork, code, and original score use the project's MIT license.
Fonts retain the OFL licenses beside their files. See the video project for
Remotion dependency and usage information.
