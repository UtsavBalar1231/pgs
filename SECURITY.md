# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the repository's
**Security** tab and choose **Report a vulnerability**. Do not open a public
issue or pull request for a security problem.

Include the `pgs` version (`pgs --version`), your platform, and the smallest
repository and command sequence that reproduces the problem. If the report
involves loss or corruption of index or working-tree content, say so, and
include the `backup_id` from the error if one was printed.

## Supported versions

Only the latest release receives security fixes. Upgrade before reporting if you
are on an older version.
